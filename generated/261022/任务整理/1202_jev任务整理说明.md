# 主 change 任务清单整理说明

整理时间：2026-10-22。OpenSpec 任务编号与勾选状态没有变更：79 项中 72 项已完成，7 项待完成。主清单从 45,884 字节压缩到 11,382 字节；保留所有任务编号、状态和简明验收摘要，逐次执行记录从清单正文移出。

## 为什么原文件臃肿

这不是 OpenSpec 工具或 Markdown 解析故障。执行过程中，逐次测试输出、历史候选 SHA、供应商费用细节、过去时点的状态和运行说明被追加到同一个任务复选框下；同类证据又分散在验收报告和 integration evidence 中，造成重复、过时信息与清单混杂。tasks.md 同时承担计划、状态板和运行日志，维护成本随每轮测试累积。

## 后续维护规则

- 每个 tasks.md 只维护任务范围、当前勾选状态、简短验收摘要和证据链接。
- 一轮测试命令、SHA、精确分母、耗时、失败、skip、账单记录放在独立、日期化的 evidence/report 文件。
- 任务验收条件如需改动，先同步 proposal/design/spec/tasks，并保留整理前快照；不能通过精简文字降低门槛或改写历史结论。
- 已结束的 OpenSpec change 仍按用户明确授权的归档流程处理；不得仅为缩短任务清单而归档或删除未完成任务。
