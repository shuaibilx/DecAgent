## 新技能不能改变的约束

### Jev 与主模型

langgraph-decision-models 中的 langchain-typesafe 为 alpha 示例，其 /v1/systemone、TypeSafe 直连、LangSmith Gateway 路线都不自动替代本项目 OpenRouter Decisions API。本轮不添加该依赖、不更换 Qwen/DeepSeek/Jev、不上传密钥或 trace 到新服务。

Confidence 不能直接当正确率。保留本项目至少 95% 自动正确率、每类至少 100 个自动样本及无合格策略时人工接管的要求。不能照抄示例中“分数足够明确即可绕过置信门槛”的路由来放宽当前规则。新问题与尺度仍先审核、评测；示例延迟、Token 和分类结果不成为 DecAgent 的实测结论。

### 公开评测

eval-engineering 的 Environment/Verifier 审计、重置隔离、私有材料边界和失败来源分类可用于当前工程。其 Harbor、Task.md、World Skill 和合成任务工作流不是本项目已批准的替代实现；本轮不安装 Harbor、不生成另一套任务规格、不修改冻结 206+80 案例或官方评分方式。

当前公开基准以 OpenSpec、固定来源与原官方 verifier 为准。该技能的工具脚本也只能在已授权的隔离夹具中使用；没有运行其 SQLite 状态导出或模型模拟器。本轮只做 Python 语法检查，不宣称脚本已完成环境或业务验收。

mcp-builder 的十道只读问答可作为工具接口的辅助检查，不能替代完整业务工作流对照，也不能将结构化分支强行改为 Jev 判断。

### 事务、CI 与部署

PostgreSQL 技能不覆盖公开控制面的 SQLite 原子预算、生命周期锁或进程树取消。对应实现继续依据 SQLite 官方文档与真实竞争/崩溃测试验收，eval-engineering 的 SQLite 快照脚本也不提供事务正确性保证。

gh-fix-ci 聚焦失败的 PR checks；github-actions-efficiency 可帮助定位 CI 延迟，github-actions-hardening 用于审阅 Actions 权限与 runner 边界，但二者来自社区贡献内容。流水线事实以 GitHub 官方文档、实际 workflow 和运行记录为准；自托管 Runner 仍走私有部署仓库，不能因技能建议重新开放公共 self-hosted 调度。Cloudflare security-audit 只在明确安全审计任务中按其 sandbox 门槛使用。

## 使用与维护

从 DecAgent 根目录打开任务，项目本地技能可在后续轮次被发现；若当前会话仍位于旧 Waku 目录，按这里的绝对项目位置或本索引链接读取。技能只辅助开发，不属于 Agent 对外的业务 Skill，不会进入业务工具注册表。

框架代码先读 ecosystem-primer，再按改动读取基础、人工介入或持久化技能；Jev 路由审阅再读 langgraph-decision-models；评测边界审阅按需读取 eval-engineering 的相关参考。安装不等于执行其全部流程，项目既有授权、固定模型、预算与规格优先。

后续更新固定提交前先审阅差异、许可证和包内资源，重新生成摘要。没有为本项目找到直接匹配的官方 SQLite 事务或 Qwen 计费技能，不用不相干的支付/云平台技能凑数；这些部分继续用已核验的供应商价格、官方文档与项目测试。
