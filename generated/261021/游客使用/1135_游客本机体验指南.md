# DecAgent 游客本机体验指南

> **你将：** 在本机合成业务工作台中开始游客体验、切换模拟员工并安全清空空间。
> **你需要：** 已启动 DecAgent 的本机服务，以及已完成迁移的 PostgreSQL 数据库。

2026-10-21 版本核对：当前 `127.0.0.1:8000` 仍运行 v0.1.4 旧镜像，`/api/v3/guest/status` 返回 404，不能用于本指南的新游客功能验收。后续需在候选对应的独立实例、一次性测试数据库中执行；不要为试用直接迁移当前业务库。

本指南只适用于本机受控试用，不代表公开注册服务已开放。
当前游客入口默认关闭，资源预算和队列门禁尚未完成。
入口隐藏时，请停止操作，不要在公网实例上自行打开该开关。

## 1. 查看游客入口

打开受控测试实例的工作台地址，以启动时实际分配的端口为准。页面只在服务端允许游客试用时显示“开始游客体验”。
入口的默认值由 `DECAGENT_GUEST_TRIAL_ENABLED` 控制，默认是 `false`。
该默认值是源码契约；旧服务中入口隐藏或状态接口 404，不能证明新版本的开关行为已验收。

本项目目前没有游客公网地址，也没有跨设备账号恢复。
Docker Desktop 或本机网页可用，不代表服务已对外发布。

## 2. 开始或恢复体验

选择“开始游客体验”后，服务为当前浏览器创建独立的模拟公司空间和预设员工身份。
浏览器持有安全 Cookie；员工身份、CSRF 和 workspace 由服务端解析。
刷新页面时，工作台使用同一浏览器会话恢复当前身份。

如果浏览器重启后仍在有效期内，可以在同一浏览器恢复会话。
清理站点数据、换浏览器或换设备后，不能找回原空间。

## 3. 切换模拟员工并查看业务

使用页眉的“体验身份”下拉框切换预置员工、处理人或主管。
切换后，页面清空旧身份的任务、工单、操作、审批、追踪与记忆视图。
已有任务仍属于创建它的员工；切回原身份才能继续查看该员工的任务和待办。

游客只看到当前已注册的模拟业务和本空间数据。
当前模拟服务工单使用合成数据，不连接御龙后端或真实公司 API。

如果业务流程暂停并显示“Jev 建议”，先检查问题、选项和证据，再提交语义选择。
语义选择不等于批准写操作；写入仍需独立确认。
真实 Jev 来源和在线决策质量尚未通过本地 live 验收，不要把展示的建议视为准确率承诺。

## 4. 清空游客空间

选择“清空游客空间”。服务立即停用 workspace，撤销浏览器/MCP 凭证并禁用模拟员工。
页面返回登录状态后，当前游客不能再访问该空间，也不能恢复该会话。

后台只会在任务 Worker 和操作临界区退出后清理数据与 checkpoint。
如果租约或操作回执仍有歧义，清理会等待并保留恢复材料，不会重放操作。
丢失清空响应时，同一浏览器的原请求可安全重试。

## 5. 会话失效

连续 7 天没有有效的本人操作后，会话过期并拒绝访问。
后台轮询、状态恢复和事件流不会延长期限。
过期数据会进入受限清理流程；游客没有恢复入口。

## 当前验证边界

既有记录包含已启用隔离构建的浏览器验证：开始、刷新恢复、角色切换和清空返回登录状态。尚未在本指南对应候选的独立实例重新完整走通，不能将当前 8000 端口的旧页面作为这项证据。
Node 工作台回归覆盖会话提示和身份缓存清理；确定性语义界面测试覆盖 Choice、Noul、Score、无匹配、补充和拒绝。
真实 Jev 请求、公开用户注册、游客预算准入和公网访问仍未验收。
