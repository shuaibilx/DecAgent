# 千问平台费率核验

核验日期：2026-10-21；快照生成时间：2026-10-21T14:41:04+08:00。用户明确确认该定价页适用于当前 API，账户可调用模型族为千问与 DeepSeek。本文在源码实施后补记版本化评测 profile 的绑定结果；未发起模型请求、未修改生产运行时模型路由，也未改写旧 profile、历史 manifest 或账单。

## 来源与端点

[用户指定的 API 定价页](https://platform.qianwenai.com/pricing/api) 的表格动态加载。此次读取其公开前端组件及同页使用的 ListModelSeries 数据接口，未携带账户密钥、Cookie 或登录凭证，也未调用余额/账户账单接口。[平台模型接入文档](https://platform.qianwenai.com/docs/developer-guides/getting-started/latest-model) 给出的 base URL 与项目的 https://maas.qianwenaiapi.com/compatible-mode/v1 一致。

页面中文站点的文本表格以 CNY / M tokens 展示；国际站美元分支不能混用。原始价格条目、公开请求 ID、来源代码摘要及提取范围见 [机器快照](1441_千问平台费率来源.json)。只提取当前相关三款模型，不声称已下载全部 125 个模型系列。

## 当前 Qwen 主模型

模型：qwen3.8-flash。以下为标准同步模型 Token 价格，单位均为人民币元/百万 Token：

| 项目 | 单价 |
| --- | ---: |
| 普通输入 | 0.8 |
| 输出 | 2.7 |
| 隐式缓存命中输入 | 0.1 |

若输入总量 I 已包含可验证的缓存命中量 C，且当前调用不存在其他计费项，则冻结费率计算值为 ((I-C)×0.8 + C×0.1 + O×2.7) / 1,000,000 CNY，其中 O 为已知输出 Token。没有缓存分项不能擅自套用缓存优惠；缺用量也不能据价格补造用量。

公开条目另有 Batch File、Batch Chat 和显式缓存创建/读取价格，已原样保存在机器快照。本项目不能仅因价格更低就把普通实时请求按 Batch 计费；显式缓存创建也不能当普通输入或免费操作。

## 同平台 DeepSeek 参考

单位同为人民币元/百万 Token：

| 模型 | 时段 | 普通输入 | 输出 | 缓存命中输入 |
| --- | --- | ---: | ---: | ---: |
| deepseek-v4.1-flash | 忙时 | 2 | 8 | 0.2 |
| deepseek-v4.1-flash | 闲时 | 1 | 4 | 0.1 |
| deepseek-v4.1-flash-1017 | 忙时 | 2 | 8 | 0.2 |
| deepseek-v4.1-flash-1017 | 闲时 | 1 | 4 | 0.1 |

同页中文组件标注忙时 8点–22点、闲时 22点–次日8点。该标签的时区本次未独立核验；后续若采用此线路，预留可先使用忙时上界，实际结算需确认适用时段。

这些是千问平台线路的价格。既有备用配置 OpenRouter deepseek/deepseek-v4.1-flash 的提供方和计价来源不同，不能把本表套到该备用线路。此次没有切换备用端点，也没有选择新的主模型。

## 对后续计划的影响

1. 10.8.D 已完成实现：[`evaluation_model_profiles_v4.json`](../../../evals/benchmarks/manifests/evaluation_model_profiles_v4.json) 为 Qwen primary/user-simulator/judge 冻结 CNY 输入/输出/缓存费率、币种、来源与版本；[`comparison_trial_manifest_v8.json`](../../../evals/benchmarks/manifests/comparison_trial_manifest_v8.json) 以新 profile digest 绑定原有 206+80 denominator、24 smoke 与 4 首波任务。v8 是 `pre_registered_not_run`，不是模型评测结果。
2. profile 基于可核验的公开标准价计算 gross API 成本，`frozen_rate` 或 `frozen_rate_upper_bound` 与供应商逐请求账单严格分开。缓存命中数量可核验时按 ¥0.1/M 计算；响应未提供缓存细项时按 ¥0.8/M 普通输入费率计算保守上界。实际 voucher、cash paid 和 invoice ID 只有供应商逐请求返回时才记录；公开标准价不是账户 invoice。
3. Jev 的 OpenRouter USD 累计账本继续独立。尚无冻结且可核验的 CNY/USD 汇率，不能把人民币 Qwen 与美元 Jev 直接相减，也不能把 CNY 金额套入美元硬预算；跨币种正式成本比较与游客费用准入仍待补齐。
4. 不回写历史 v2/v3 profile 的零费率假设，不改写 v5/v6/v7 manifest，不重结历史 unknown、不释放预留、不重发请求。公开数据中的 UpdateAt 是条目更新时间，不直接当价格追溯生效日。
5. 账户可用范围按用户确认限制为千问/DeepSeek；公开目录中其他厂商模型不自动成为本项目可用模型。Jev 仍走既有独立 OpenRouter 配置。

确定性验证：profile、manifest、账本结算、缓存用量解析与历史兼容的四个定向文件 `118 passed`；primary usage suite `119 passed`。没有请求 Qwen、DeepSeek、Jev、MCP 工具或公开评分器；账单和券抵扣仍未从账户侧读取。
