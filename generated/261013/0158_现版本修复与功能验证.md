## 已修复的行为

完成声明按非空 `W ⊆ C ⊆ O` 核实。`O` 是完整已核实操作，`W` 是其中的写入，`C` 是模型声明的完成 ID。允许不引用辅助读取；写入必须全部引用，陌生 ID 不允许引用。最终目标、单一资源与持久回执仍基于完整 `O` 校验。程序不能证明注册目标时返回 `goal_unproven`，保存已有证据，停止为 failed。目标识别仍有确定性词汇范围；使用明确注册操作或精确 JSON 请求，重新提交前核实已发生写入。

完整主模型响应或正常结束流的提案被拒绝时，严格合法的用量、安全原样的实际模型名与固定拒绝原因分别保存并结算；所有提案都被拒绝。布尔/负数/字符串/不相等的 token 合计不修补为合法用量。流中断、缺失或非法用量、供应商伪装异常仍按未知处理。可信本地派发前预检可以证明调用未发生时按零结算。业务记录、旧修复等待和主模型诊断保存安全证据；重启/相同 operation ID 不重新派发。已知 tokens 而价格未知时，费用仍未知。
