# MCP 源码结构与逐脚本职责

源码入口：runtime/application → gateway/app → business/worker → business/graph → business/services → business/execution → mcp_client → mcp_server → operations → tickets/store。

```text
DecAgent/
├─ decagent/       产品源码
│  ├─ business/    员工身份、规划、MCP、操作事务与恢复
│  ├─ gateway/     员工/owner API 与静态工作台
│  ├─ runtime/     应用装配、调度、主模型记账和修复图
│  ├─ decisions/   Jev 类型化问题、校准、持久判断
│  ├─ storage/     迁移、checkpoint、预算、审计和备份
│  ├─ executor/    仓库修复隔离执行
│  ├─ tools/       固定修复工具
│  ├─ memory/      既有修复任务的记忆生命周期
│  └─ evaluation/  历史报告与当前 MCP 验收
├─ ops/            运维脚本（operations 的缩写）
├─ evals/          测试与固定验收材料
├─ generated/      日期归档的说明、图册、截图、报告
└─ .decagent/      私有凭据与本机运行数据
```
