# 数据、预算、迁移与备份

应用表在 PostgreSQL `app` schema，LangGraph checkpoint 在独立 `checkpoint` schema。
运行证据默认在 `.decagent/evidence/<sha256>`；不读取或删除原项目 `.waku`。

设置 `DECAGENT_DATABASE_URL` 后运行 `python -m decagent migrate`，首次建表，
再次执行保留数据。应用迁移通过事务 advisory lock 串行化，校验版本与源 SQL 哈希；
checkpoint setup 在自己的 schema 内执行。已有活动任务的 graph 版本不兼容会明确报错，
不会自动丢弃 checkpoint。后续 schema 修改必须增加版本迁移。

动作按 `(task_id, logical_key)` 去重，变更摘要不复用旧动作。审批绑定摘要，回复在
行锁中一次性消费；事件 seq 由任务行原子递增。worker lease 有 owner、generation、
过期时间；老 worker 即使恢复也不能通过 fencing 检查。

## 预算

调用前预留最大 token 和预计费用，每次重试单独计入调用次数。金额用 Decimal，
未知使用量或未知费用保持预留，只有真实 usage 与金额齐全后才结算。
缺价格不能当作免费；仅在 owner 明确授权 bounded calls 时允许未知价格调用。
付费基准不能使用这个例外。人工等待应暂停 active time，实际 worker 集成仍需验收。

`UsageLedger` 在任务行锁内检查预算并持久化预留，重启后仍有效。
纯 `Budget` 用于确定性测试/单进程适配器；不能替代生产数据库账本。
真实 provider 价格映射需用户确定，在未配置价格时没有自动推测报价。

## 备份恢复

```powershell
# 从源实例导出到不存在的新路径，配置源 database URL 和 data dir
python -m decagent backup ./backups/instance-01
# 改用新的空 PostgreSQL 数据库及新的 data dir 后恢复
python -m decagent restore ./backups/instance-01
```

`snapshot.json` 保存 repeatable-read 数据库快照，包含 checkpoint 的二进制数据。
`manifest.json` 保存快照哈希、各表行数和证据长度/来源。只复制快照引用的不可变证据。
恢复先校验快照和证据哈希，再检查当前迁移版本和表集合，按外键顺序插入原 ID。
目标 evidence 目录必须不存在，数据库业务表必须为空；已有数据会被拒绝，不提供清空选项。
失败恢复保留目标文件供检查，应换新的目标目录继续，不删除故障卷。

这些文件包含认证哈希和私有仓库资料，应按实例数据保存。备份工具不保存模型/PAT明文。

## 本地验收

真实 PostgreSQL 17 的临时数据库测试覆盖：重复迁移保留数据、跨项目外键拒绝、
并发领取唯一 worker、stale generation 拒绝、并发事件连续 seq、审批重复回复拒绝。
备份测试创建另一个新数据库并恢复任务、审批、checkpoint、证据，核对证据哈希；
不会重置用户数据库。未集成的 worker 取消/active time 和完整 Compose 恢复另行验收。
