实施目标是原 Waku 同级目录 `DecAgent/`，独立包名/命令为 `decagent`。
原项目的 `.env`、`.waku`、`.venv`、日历、语音、Telegram 业务未导入。

正式 OpenSpec 规划仍在 `../../openspec/changes/build-decagent-workbench/`。

## Conda 与 pip

从 **DecAgent 根目录** 执行：

```powershell
conda activate Agent311
python --version
$env:PIP_CONFIG_FILE = "nul"
python -m pip install --index-url https://pypi.org/simple -r requirements.txt
python -m decagent --help
python -m decagent doctor
```

`PIP_CONFIG_FILE=nul` 只在当前 PowerShell 会话屏蔽旧 pip 配置，避免原 NVIDIA
extra-index SSL 错误；没有关闭证书检查。当前 Agent311 名字带 311，但实际解释器是
Python 3.13.13。本项目声明 Python >=3.11，使用 Windows 干净 3.13 venv 和 Linux
Python 3.11 容器验证，不依赖宿主机 uv。

`requirements.lock` 锁定实际解析的直接与传递依赖，`requirements.txt` 先读锁文件，
再执行 `-e .`：把本地 DecAgent 注册为可编辑包，并核对 pyproject 依赖。
模型、Jev 和 GitHub 密钥分别配置，不能用其中一个密钥替代另一个。

开发安装：`python -m pip install -r requirements.txt -e ".[dev]"`。
验证：`python -m ruff check .`、`python -m pytest evals/deterministic -q`。
`ops/verify_install.py` 验证导入、pip check、帮助与免费配置诊断。

## 模块职责

| 路径 | 职责 |
|---|---|
| decagent/__main__.py、cli.py | 包入口与本地管理命令，按命令延迟装配组件 |
| config.py | 控制服务配置；拒绝混用 `.waku` 数据和远程明文 HTTP |
| storage/database.py、schema.sql | PostgreSQL 显式 SQL、约束、版本迁移、事件序号、审批与 lease |
| storage/evidence.py | 脱敏后按内容哈希保存证据，读取时校验长度和哈希 |
| storage/budget.py、usage.py | 调用前预留、未知使用量保留、跨重启的使用量账本 |
| storage/backup.py | 一致性数据库与证据备份，只恢复到新实例 |
| policy/ | 工具参数、授权来源、信任范围、硬规则与审批绑定 |
| decisions/ | 独立 TypeSafe 协议、判断策略、校准和降级 |
| runtime/ | 后续持久化图与任务 worker 的模块边界 |
| models/ | 后续主生成模型适配边界 |
| tools/、executor/ | 后续小工具与受限执行边界 |
| memory/、integrations/、gateway/ | 后续项目记忆、GitHub 集成、认证工作台边界 |
| ops/ | 运维脚本；不是仓库任务代码运行的位置 |
| evals/deterministic、integration、live | 离线单元、真实本地服务、明确授权的真实外部检查 |
| generated/ | 生成的说明和验收记录，与源码及运行数据区分 |

`.env.example` 是模板，不包含真实凭据。`Settings.from_env` 读取进程环境；
当前 CLI 不自动读取 `.env`。未完成的图/执行器/工作台不能按产品完成使用。
