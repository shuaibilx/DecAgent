本轮实现了用户确认的“扩展隔离评测工具注册，复用生产执行器”。OpenSpec 仍为 **52/60**；9.6 和第 10 组真实验收仍未全部完成。公开任务执行数保持 **0/286**，本轮模型请求为 **0**。

## 已落地的执行边界

| 组件 | 当前行为 |
| --- | --- |
| EvaluationScope / EvaluationCatalog | 只由可信评测代码创建；绑定固定工具 schema、版本和一次性作用域，关闭后不能继续编译或执行 |
| 生产执行器 | 原始公开工具使用同一 compiler、类型化 binding resolver 和 PlanRuntime |
| 隔离日志 | 每次试验独占 SQLite 文件；保留计划、节点、参数来源、每次真实工具响应及未知结果 |
| Enterprise / τ session factory | 每个路线新建环境和日志；τ 工具通过真正的内存 MCP list/call 协议执行 |
| 完成与评分 | `evaluation_execution_finished` 只证明计划观察完成；业务成功由上游官方 verifier 单独决定 |
| 生产业务 | PluginSpec/Registry/HTTP 没有新增通用目录入口，公司身份和写入确认约束继续生效 |
| 语义模板 | 公开目录暂不发布新 Jev 判断；无可信模板时拒绝 decide，不动态生成问题或评分尺度 |

~~~mermaid
flowchart LR
    H[可信评测 harness] --> S[新环境与活动 Scope]
    S --> C[固定原始 MCP Catalog]
    C --> P[生产 Compiler / Bindings]
    P --> R[生产 PlanRuntime]
    R --> J[每试次 SQLite 日志]
    R --> M[原始 MCP 工具]
    M --> O[原始成功或错误响应]
    O --> J
    R --> F[execution_finished]
    S --> V[私有官方 verifier]
    V --> B[业务任务成功或失败]
    F --> D[报告分别记录执行与业务结果]
    B --> D
~~~

EnterpriseOps 当前初始状态身份由固定快照摘要、域与恢复上下文构造，尚未独立测量全部活库行状态；正式公平配对仍需补充恢复状态验证。τ 完整可选运行时未安装，协议夹具不等于官方任务环境验收。

## 本轮修复与验证

- 恢复节点核对计划节点、输入和 provenance，不能以新参数静默复用旧调用。
- 自定义 task input schema 在节点启动、派发和恢复时保持一致。
- 公开工具结果不能伪装成公司 write_receipt；生产执行器拒绝评测专用完成回调。
- 明确收到的 MCP `isError=true` 保留为原始工具错误：ReAct 可读取错误并继续，计划走显式 `on_error`。只有传输未知写入才暂停且禁止重放。
- 所有计划/ReAct 工具调用保存完整成功或错误响应；旧日志缺少观察列时明确拒绝恢复，不伪造缺失响应。
- 延迟分列环境准备、Agent 区间、私有评分、清理及总墙钟。Agent 区间包含规划、编译、绑定和工具执行；机器耗时减去观测到的人工/模拟器等待。环境未完成初始化时标记 `agent_started=false`。
