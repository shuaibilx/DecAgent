## 分组、划分与预算子集

种子固定为 20261015。所有分组只观察 utterance：NFKC / casefold / 标点与空白归一化；可识别占位符、邮箱、URL、数字归为模板槽；长度至少 10 token 的序列按至多一个 token 插入、删除或替换形成近重复关系，再取传递连通分量。标签只用于分层和评分。规则版本为 lexical-components-1；这是保守词法规则，不能证明识别了全部语义改写或全部生成模板。

Bitext 没有官方 split：按文本组原子分配，以标签目标误差最小化的确定性贪心方法尽量达到 60/20/20。CLINC 保留官方 train / val / test 及对应 oos 划分的来源，不搬移任何样本；识别到跨官方划分的组时，全组明确排除。相同归一化文本只保留 ID 排序最先的一条；相同文本不同标签则排除，避免隐藏标签冲突。所有排除项保留原 ID、官方 split、group_id 和原因。

| 配置 | 原始条数 | 可用开发 / 验证 / 测试 | 排除 | 预算验证 / 测试 |
| --- | ---: | --- | --- | --- |
| kaggle-bitext | 21534 | 11756 / 3923 / 3912 | normalized_duplicate=1943 | 270 / 540 |
| clinc150 | 23700 | 14914 / 3041 / 5397 | cross_official_split_group=320, normalized_duplicate=28 | 400 / 800 |

CLINC 子集分别保留官方验证的 100 条 OOS + 每个 in-scope 类 2 条（共 300），官方测试的 200 条 OOS + 每类 4 条（共 600）。没有跨 split 补样。Bitext 在同一 split 内按标签平衡轮转、固定种子取样，缺少某类时由同 split 其他类补足总预算；真实分布写入 subset_label_counts。

Bitext 总数达到 270/540，但存在以下类平衡约束，不能称为每类都达到等额样本：

| split | intent | 名义等额最低数 | 实际 / 同 split 可用 |
| --- | --- | ---: | --- |
| validation | cancel_order | 10 | 7 / 7 |
| test | cancel_order | 20 | 6 / 6 |
| test | place_order | 20 | 13 / 13 |
| test | set_up_shipping_address | 20 | 17 / 17 |

两份数据的总预算 shortfalls 均为空；类平衡不足独立记录在 stratification_shortfalls。样本 ID 与 group_id 已冻结，测试样本不得用于模板、策略或阈值调优。不要把同一组内相关样本当成统计独立的业务任务。

## 使用与复现

工作目录：`<DecAgent 仓库根目录>`。所有命令均为独立数据工具，不启动现有 business-2 框架或模型/数据库。

```powershell
.\.venv\Scripts\python.exe -m decagent.evaluation.business.conditional.dataset_cli config --source kaggle-bitext
.\.venv\Scripts\python.exe -m decagent.evaluation.business.conditional.dataset_cli fetch --source kaggle-bitext
.\.venv\Scripts\python.exe -m decagent.evaluation.business.conditional.dataset_cli prepare --source kaggle-bitext
.\.venv\Scripts\python.exe -m decagent.evaluation.business.conditional.dataset_cli fetch --source clinc150
.\.venv\Scripts\python.exe -m decagent.evaluation.business.conditional.dataset_cli prepare --source clinc150
```

已存在的 acquisition.json 和 frozen.json 会拒绝覆盖。需要重新核对下载时，用新的 `--root .decagent/conditional-evaluation/data-recheck`；只需重新计算相同数据的样本清单时，用新的 `--output <path>`。`prepare --data <pinned-file> --license <local-license>` 支持显式离线导入，但仍逐字节验证已固定的数据和许可 SHA256，其他发布源/版本不能冒用配置名称。导入时间是 imported_at；真正网络获取时间只来自 acquisition.json 的下载流水。重算时文件整体哈希可因导入时间改变，sample_list_sha256 应保持一致。

公开来源不可用、许可未核实/缺失、数据缺失、来源字节哈希变化或格式错误都返回非零退出码 2；fetch 能将失败原因落为 pending。失败不标为已跑公共基准，也不自动改用 HF 镜像。检查 pending 后应选一个新的 root 再尝试，保留失败证据。

`frozen.json` 包含完整本地可用 split、预算 subset、隐藏评分标签、排除项和 manifest，因此不能整体发给模型。模型输入必须通过 `datasets.model_input(record, options=legal_options)`，白名单只复制 utterance 与调用方给定合法选项。intent / label / category / flags / response / answer 及原始 record 中注入的 options 都不会自动传入模型。
