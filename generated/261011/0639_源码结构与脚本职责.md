# DecAgent 源码结构与脚本职责

默认业务按 `cli.py → business/administration.py → gateway/business.py → business/worker.py → business/graph.py → business/services.py` 阅读。
保留修复按 `runtime/application.py → runtime/worker.py → runtime/graph.py → runtime/services.py` 阅读。
`gateway` 是用户接入层；`ops` 放部署、诊断和运行维护脚本。下方旧模块索引保留，本轮业务及新增脚本单独逐文件列明。

```text
DecAgent/
├─ decagent/                 产品 Python 包
│  ├─ gateway/               认证 API、网页和 CLI 客户端
│  ├─ business/              契约、三类判断、治理、持久图和独立工单 CLI
│  ├─ runtime/               装配、worker、LangGraph 与模型记账
│  ├─ policy/                硬策略、信任和审批
│  ├─ decisions/             Jev 独立判断与校准
│  ├─ models/                主模型适配
│  ├─ executor/              broker、Docker 与网络代理
│  ├─ tools/repair/          受控修复和固定验收
│  ├─ integrations/          GitHub 与草稿交付
│  ├─ memory/                项目记忆生命周期与上下文
│  ├─ storage/               SQL、证据、预算与备份
│  └─ evaluation/            数据集、对照实验与发布门槛
├─ ops/                      可信运维与 runner 脚本
├─ evals/                    回归测试、固定材料和实验数据
├─ generated/YYMMDD/         生成的说明、图册和验收报告
└─ .decagent/                私有凭据和运行证据，不提交 Git
```

各目录的 `__init__.py` 定义包边界与公共导出。它们分别位于 `decagent/`、`business/`、`business/tickets/`、`decisions/`、`evaluation/`、`evaluation/business/`、`executor/`、`gateway/`、`integrations/`、`memory/`、`models/`、`policy/`、`runtime/`、`storage/`、`tools/`、`tools/repair/`；导入包不会授予执行权限。

## 入口与主模型

| 脚本 | 职责 |
| --- | --- |
| `decagent/__main__.py` | 接收 `python -m decagent`，转交 CLI。 |
| `decagent/cli.py` | 初始化拥有者、启动服务、查询/取消/恢复任务、迁移、备份、发布与介入报告；不在宿主执行仓库代码。 |
| `decagent/config.py` | 加载控制服务环境和 `.env`，隐藏密钥字段；不把配置对象传进任务容器。 |
| `decagent/models/primary.py` | 通过 LangChain 适配主模型；独立严格核实流式用量和安全原始模型名，完整拒绝响应与可信派发前拒绝分别使用安全异常；不执行工具。 |

## 接入层 gateway

| 脚本 / 文件 | 职责 |
| --- | --- |
| `gateway/app.py` | FastAPI 接口、认证约束、任务和审批、SSE、记忆审核、配置摘要及诊断；事务保存幂等请求。 |
| `gateway/auth.py` | 拥有者令牌哈希、过期 session、CSRF、Origin 和注销。 |
| `gateway/client.py` | CLI 使用的认证 HTTP 客户端；从受保护文件读令牌，不使用命令参数传密钥。 |
| `gateway/models.py` | 严格接口输入 DTO，拒绝多余字段及不当类型。 |
| `gateway/static/index.html` | 登录、仓库登记、任务、审批、预算、记忆与诊断页面结构。 |
| `gateway/static/app.js` | 用户交互、API 请求、SSE 续传与事件去重、结果渲染。 |
| `gateway/static/style.css` | 工作台视觉与布局。 |

本节后续省略公共前缀 `decagent/`。

## 运行时 runtime

| 脚本 | 职责 |
| --- | --- |
| `runtime/application.py` | 组装默认 API 回调、GitHub 身份诊断、broker 控制和发布核实。 |
| `runtime/config.py` | runner、broker、策略、价格与上下文上限，属于实例配置。 |
| `runtime/context.py` | 从认证记录、项目归属与持久快照还原策略上下文；不从模型文字读取授权。 |
| `runtime/worker.py` | SQL 队列串行消费者，续租、代次检查、checkpoint 恢复和任务间记忆维护。 |
| `runtime/graph.py` | LangGraph 节点/边、工具循环、结果边界的 progress/replan/help 与持久中断恢复。 |
| `runtime/progress.py` | 纯函数归一化观察、重复/失败信号、最多两次调整及反馈轮次；证据新颖性不等于成功。 |
| `runtime/intervention.py` | 独立 task_intervention 判断、模型建议与实际路由、证据化问题和持久反馈。 |
| `runtime/services.py` | 把工具提案接到治理、broker、修复、记忆和交付；处理已知失败与未知效果。 |
| `runtime/operations.py` | 可恢复的控制器动作，复用同一审批和执行边界。 |
| `runtime/decisions.py` | 新动作独立风险判断与工具治理，恢复时兼容旧双问题记录。 |
| `runtime/model_calls.py` | 每个主模型请求先预留调用、token、费用；完整拒绝仍按合法用量结算，可信未派发结算零，未知用量/价格保持对应预留。 |
| `runtime/model_diagnostics.py` | 拥有者选定的单模型诊断，先提交意图，单次预留上限 $0.05；拒绝与预检失败保留可核实用量，同一操作 ID 复用结果而不重发。 |
| `runtime/memory.py` | 从当前任务的真实验证事实构建候选，绑定来源 blob 和验证记录。 |

## 治理 policy 与判断 decisions

| 脚本 | 职责 |
| --- | --- |
| `policy/models.py` | 不可变动作、来源、认证、信任、代码快照和策略数据。 |
| `policy/tools.py` | 严格工具参数、类型和字段范围。 |

| `policy/paths.py` | 跨平台路径检查、敏感位置和越界拒绝。 |
| `policy/approvals.py` | 纯审批状态转移、规范化摘要、一次性使用和设计确认绑定。 |
| `policy/canonical.py` | 带用途域的稳定 JSON 规范化及摘要。 |
| `policy/redaction.py` | 统一密钥、输出与敏感信息过滤。 |
| `decisions/contracts.py` | Choice/Noul/Score、问题和返回值的版本化强约束契约，兼容旧决策记录。 |
| `decisions/precision.py` | Score 概率、加权分数、confidence 与 mode 的联合舍入可行性；有界 phase-one 校验，不改写原值。 |
| `decisions/adapter.py` | TypeSafe / OpenRouter Decisions HTTP；校验概率、实际模型、重试和费用。 |
| `decisions/policy.py` | rule/main-llm/jev 共用语义路由；不能覆盖硬策略。 |
| `decisions/durable.py` | 推理前持久化意图，恢复时复用已有判断，避免重复收费。 |
| `decisions/calibration.py` | 人工标签、集合划分和仅用校准集拟合的版本化阈值。 |

## 执行边界 executor

| 脚本 | 职责 |
| --- | --- |
| `executor/__main__.py` | broker 服务入口，SQL 和真实网络自检通过后才可用。 |
| `executor/migrate.py` | 独立迁移入口。 |
| `executor/protocol.py` | 内部受限协议、执行 ID 与任务代次；调用方不能指定任意 Docker 参数。 |
| `executor/broker.py` | 认证执行服务、租约围栏、工作区、命令、取消与结果核实。 |
| `executor/docker.py` | broker 独占的 Docker API 客户端，配置固定资源与隔离，拒绝宿主路径透传。 |
| `executor/archive.py` | 安全 archive 解析、权限与大小校验、文件快照；不在宿主解包未知代码。 |
| `executor/receipts.py` | 原子保存执行凭据；未知启动先核实已有效果。 |
| `executor/proxy.py` | HTTP/CONNECT 代理，重新检查 DNS，把连接固定到公有 IP，阻止内网及元数据地址。 |

| 脚本 / 文件 | 职责 |
| --- | --- |
| `business/__init__.py` | 业务包边界；导入不授予执行权限。 |

| `business/runner.py` | 严格有界 JSON、命令数组与 shell=False、UTF-8、业务环境白名单、时间/输出/Windows Job Object 进程树和数量限制；POSIX 拒绝启动。 |

| `business/planner.py` | 从登记契约生成主模型工具；区分 ask_user、finish 与业务操作，校验已核实动作 ID。 |
| `business/actions.py` | 共用硬治理：Schema、实体、状态、revision、明确意图、确认、重名及精确 JSON 参数绑定。 |
| `business/execution.py` | 租约围栏动作日志、稳定 operation_id、预算前检查、已成功复用、未知写入 receipt/get 核实。 |
| `business/services.py` | 持久阶段编排、规则/Jev/主模型路由、延迟模型、安全拒绝及用量记录、人工问题、编辑再次确认；W⊆C⊆O、完整回执与注册目标核实。 |
| `business/graph.py` | business-1 StateGraph，Command 串行路线，human/budget/reconciliation 独立 interrupt，128 阶段上限。 |
| `business/worker.py` | 只领 business-1 业务任务；SQL 租约/heartbeat、按 task ID checkpoint、认证回复和明确恢复事件。 |
| `business/errors.py` | 未知业务执行需核实的结构化异常，接到持久恢复等待。 |
| `business/tickets/__init__.py` | 从安装包读取内置清单资源。 |
| `business/tickets/manifest.json` | service-tickets 1.0.0 的 Schema、命令效果、确认、receipt、workflow、题目和尺子。 |
| `business/tickets/SKILL.md` | 可信任务资料：目录、生命周期和回执核实；不能扩大执行权限。 |
| `business/tickets/cli.py` | 独立 UTF-8 JSON stdin/stdout CLI，只接 command/params/operation_id；不加载模型、owner 或 GitHub 密钥。 |
| `business/tickets/store.py` | PostgreSQL 工单目录和状态操作；expected_revision、历史、输入摘要与回执同事务提交。 |
