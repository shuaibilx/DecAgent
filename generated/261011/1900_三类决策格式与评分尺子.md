# 三类决策格式与评分尺子

DecAgent 使用独立的 Decisions API 获取类型化判断。主模型负责规划；问题、选项来源、评分等级和执行权限由版本化程序及插件契约定义。

## Choice：有限候选选择

操作候选来自已注册命令，并按当前工单状态过滤。人员、分类候选来自实际 directory 查询，持久化查询来源及候选 ID。`no_match` 表示没有唯一、有依据的匹配。模型不能创造人员 ID；人员重名而缺少部门等区分信息时应请求澄清。

请求的 `criteria` 是选项到描述的映射。响应包含 `choice`、覆盖全部选项的 `probabilities`、`confidence`。程序校验概率和、最高概率选项与置信度的一致性。

## Noul：单一命题

例如“用户明确指定了处理人”“影响超过一个人”。响应的 `noul` 表示命题成立的概率。问题不能把两个不同的命题混在同一个判断里；业务校准使用 `max(p, 1-p)` 衡量判断确定性。

## Score：有序情境等级

工单的工作受阻程度使用如下初始尺度：

| 等级 | 情境 | 新工单优先级建议 |
| --- | --- | --- |
| 0 | 工作未受影响 | 得分小于 0.5：normal |
| 1 | 有替代方案，工作可继续 | 0.5 至小于 1.5：high |
| 2 | 工作受阻 | 1.5 至 2：urgent |

请求的 `criteria` 是按顺序排列的 2 至 10 个情境描述。响应包含 `score`、`probabilities`、`confidence`、`legend`；等级索引为字符串 `"0"`、`"1"`、`"2"`。`score = Σ(i × p_i)`，因此可以是 1.4 这样的加权平均值。

Score 的置信度利用分布在有序等级上的距离，不能套用 Choice 的置信度公式。程序校验完整分布、加权均值、等级描述及官方置信度定义，拒绝 NaN、布尔值伪装数值和不一致结果。参考 [TypeSafe Score](https://docs.typesafe.ai/primitives/score) 和 [置信度定义](https://docs.typesafe.ai/confidence)。

评分只提供新工单的优先级建议。修改已有工单优先级仍须用户确认；评分也不能授予执行权限、证明任务成功或替代写入回执。

## Wire 小数精度

2026-10-12 的 OpenRouter Jev 1.13 真实响应独立舍入概率、score 和 confidence。
例如概率 `(0.87,0.05,0.08)`、score `0.22`、confidence `0.68`，不能要求从已舍入概率重算的 `0.21` 与 score 完全相等。
官方示例也将精确 `0.355` 的 confidence 展示为 `0.35`。

本地校验给百分位对齐的数值半个单位 `0.005` 的兼容区间；更高精度数值不套用这个单位。
区间必须能容纳总和为 1 的分布，且同一分布须同时解释 Score、confidence 和最高概率等级。
例如上述概率配 `score=0.22, confidence=0.70` 仍被拒绝。
不归一化或改写供应商原值；原分布、score 和 confidence 留在证据中，校准也使用原值。
这描述本次观测精度的兼容策略，不声称供应商保证所有响应均为两位小数。
实现为 `decagent/decisions/precision.py`；错误类型、范围、候选或 legend 仍触发降级。

参考 [TypeSafe 的响应字段](https://docs.typesafe.ai/sdk/python/api/types/responses) 与上方 Score/置信度定义。

## 版本与校准

完整问题、题目版本、契约摘要、候选来源、最小化状态、实际模型版本、原始答案和最终路由应随业务任务保存。三种判断的校准分别处理；置信度不等于真实准确率。

业务开发集使用 synthetic-reference 标签，与独立人工标签分开记录。实际模型版本改变、缺少兼容校准、低确定性、超时或非法响应时，路线应进入有预算的主模型或具体的人工澄清。合成校准不能证明真实企业环境准确率。

## 实现与回归

核心类型位于 `decagent/decisions/contracts.py`，HTTP 适配器位于 `decagent/decisions/adapter.py`。原有 Choice/Noul 及旧仓库修复决策路径保持独立；新增业务校准不会降低旧策略的审查要求。

从项目根目录执行：

```powershell
python -m pytest evals/deterministic/test_score_decisions.py evals/deterministic/test_decisions.py evals/deterministic/test_decisions_calibration.py -q
```
