# 评测数据与统计限制

> 历史资料说明（2026-10-12 更新入口）：本页保留历史 Python 修复评测材料、人工标签与统计限制。原命令、测试数量、费用和通过状态仅适用于当时范围；不作为当前业务 Agent、真实模型提效或独立 Linux 部署的验收结论。
>
> 当前入口：[业务使用指南](../261012/0852_业务Agent使用指南.md)、[业务架构](../261012/0852_业务Agent架构详解.md)、[离线图册](../261012/0902_业务Agent架构图册.html)、[本机业务验收](../261012/0900_本机业务验收记录.md)。业务题目与 synthetic-reference 校准/40+80 评测见[当前评测说明](../261012/0844_业务基准评测说明.md)。

当前证据证明评测工具可以追踪费用、保存失败并回放 12 个真实 Python 历史问题。
它没有证明任何模型的修复成功率、决策准确率或 Jev 的收益。

## 来源与许可

历史缺陷覆盖 Flask 4 个、Requests 3 个、pytest 5 个。
[SWE-bench](https://github.com/SWE-bench/SWE-bench) 仅用于发现问题编号和基线 SHA。
简短问题说明由本项目改写。代码和验收改编来自真实上游 PR，保留固定提交和原始 test patch。
许可分别为 BSD-3-Clause、Apache-2.0 和 MIT；每个 base 的完整许可文件都保存在
[licenses](../../evals/benchmarks/licenses/)。
源码下载地址含固定 SHA，压缩包 SHA256、验收 SHA256 和日志 SHA256 均保留在 manifest。

验收是对上游回归的最小外部复现，不等于全仓回归套件。
Requests #5087 用耗尽的受控响应流替代 TCP 服务，仍运行真实 Response 实现。
pytest 在未构建的 archive 中补充 setuptools-scm 通常生成的版本文件；不修改缺陷语义代码。
上游 fixture 链接明确省略。容器实际导入路径必须在 /repo/，防止错误测试已安装的同名包。

## 人工标签与校准

120 个样本全部未标注，不能计算经验误放行、误中断或记忆质量。
四类样本各 30 个，读取类包含 memory_read_needed 和 memory_relevant。
按上游问题分组划分 calibration/holdout；同一输入或 leakage_group 不跨集合。
标签必须来自独立人工判断，记录 labeler，不能来自被评测模型。

人工完成前，唯一带标签材料为明确标注 synthetic_fixture 的算法 fixture。
这些标签、预测与导出阈值是人为构造的测试数据，不能安装为实际 Jev 的生产校准。
阈值使用校准集合；保留集预测变化不会影响拟合结果。
所有自动路径还要求实际返回模型、问题、策略和数据集版本匹配。
概率和供应商 confidence 是不同统计量，都不等于实测正确率。

## 指标解释

报告的 planned 保留所有样本，failed、unknown、pending、skipped 和版本变化单独计数。
修复成功分母为全部计划任务；只有相关基线失败、独立和回归通过、有用例且无 skip/xfail 才计成功。
当前历史数据集只验证参考修复的独立复现，不能作为 Agent 修复的成功记录。

误放行指 action_risk 真值为 deny/review 但最终 route 为 allow；
误中断指 intervention 真值为 continue 却 route 为 clarify/review。
当前报表保留计划样本分母；若有未观测结果，计数只是已知错误下界，
不能解释为完整准确率。无人工标签时相应 rate 为 NULL。

记忆写入以 retain 为正例，记忆读取以 retrieve 为正例。
precision、recall_observed 和 accuracy_observed 只描述已分类结果；
review 计 abstained/unresolved，不冒充正确的负例。覆盖率与未完成计数需要同时查看。
P50/P95 用线性插值，只基于有有效非负 latency 的观测；unobserved 不能当成零延迟。
成本包括所有尝试；存在未知账单时 total_usd 为 NULL，另列 known_usd 与 unknown_attempts。
未知 token 和账单都保留其预留容量，不按零费用继续。

## 结论边界

12 个问题来自三个常见且可在 Python 3.11 运行的仓库，是便利样本；
缺陷类型与环境选择存在偏差。
公开历史 PR 可能已出现在模型训练数据中，模型成功可能受数据污染影响。
少量、一次、未随机化的实验不支持显著性或泛化声明。
真实比较应锁定相同授权、工具、硬策略、验收与主模型，只替换语义判断策略。
预算中断、模型版本变化、不可用和未完成样本必须保留，
不能缩小分母展示好看的结果。

1 USD 是整个诊断会话的共享上限，不是这个提案的可用实验预算。
当前未知主模型账单只能由根账本核实，没有被本评测工具释放。
下一次付费比较需要单独确认最终 RunManifest，当前仍未运行。

研究目录 evals/benchmarks/research/ 保留了本地发现缓存和外部源码。
自动审批拒绝清理后未绕过；局部 Ruff 与 pytest 配置排除它，发布时不能复制该缓存。
