# 业务图版本分派与回退参考

## 版本和入口

| 项目 | 契约 |
| --- | --- |
| `business-2` | 旧 `business.graph.build_graph` 与 `BusinessServices`；保留原阶段、队列、动作和 checkpoint 语义。 |
| `business-3` | 固定 `business.conditional_graph.build_graph` 与 `ConditionalBusinessServices`。初始 checkpoint 数据仅为 `task_id`、`graph_version`、`phase=prepare`。 |
| 未知版本 | 仅将被 claim 的该任务转为 `recovering`，保存 `task.waiting`、`kind=version`；其他支持版本继续处理。 |
| 版本一致性 | checkpoint 的 `data.graph_version` 必须与该任务的持久 `graph_version` 相同；不匹配进入版本恢复等待。 |
| 仓库修复 | 独立 `Worker`、`repository_repair` 队列和原图版本；业务版本混用不参与其版本检查。 |
| 数据库 schema | claim 前验证全部迁移号与当前应用一致；此检查不会要求整条业务队列只有一个图版本。 |
| 人工迁移记录 | `business_migration_pending`、缺员工或缺凭据的记录不自动执行。 |

## 开关

| 配置 | 类型 / 默认 | 作用 |
| --- | --- | --- |
| `RuntimeConfig.conditional_workflows_enabled` | 严格 `bool` / `False` | 新任务入口选择条件计划版本的部署开关。 |
| `DECAGENT_CONDITIONAL_WORKFLOWS_ENABLED` | `true` 或 `false` / 未设置时 `false` | 忽略首尾空白和大小写；空值、`1`、`0`、`yes` 及拼写错误均报错。 |
| 开关关闭后的已有任务 | 原版本不变 | 兼容 worker 继续恢复已有 business-3；不会将任务或 checkpoint 转为 business-2。 |

## Worker 注入接口

| 参数 | 适用版本 | 默认 |
| --- | --- | --- |
| `services_factory` | business-2 | `BusinessServices` |
| `graph_factory` | business-2 | `business.graph.build_graph` |
| `conditional_services_factory` | business-3 | `ConditionalBusinessServices` |
| `conditional_graph_factory` | business-3 | `business.conditional_graph.build_graph` |

注入服务 factory 的位置参数依次为 `database, settings, runtime_config, task, owner, lease_generation`。
生产默认服务另收 `mcp_client` 关键字参数。
两个 graph factory 均收 `services, checkpointer`。

## 等待与恢复

| interrupt | worker 恢复前检查 | 传入图的恢复数据 |
| --- | --- | --- |
| business-3 `decision` | 同任务 approval；`replied/consumed`；`semantic_record`；kind 和可选 digest 一致 | 仅 `approval_id`；服务再核验员工、权限、计划/候选版本及一次性消费。 |
| `action` / 原有审批 | 同任务 approval；`replied/consumed`；`policy_record`；kind 和可选 digest 一致 | 仅 `approval_id`；原具体写入确认协议继续生效。 |
| `budget` | 当前 interrupt 之后的 `task.resume_requested` | 已持久事件 payload 与当前 `kind`。额度更新仍由已认证入口负责。 |
| `reconciliation` | 当前 interrupt 之后的 `task.resume_requested` | 原操作核实请求；不创建新 operation 身份。 |
| 未回复或凭据不符 | 不发送 `Command(resume=...)` | 保留当前等待。 |
| 普通未完成节点 | checkpoint 任务和图版本一致 | `None`，继续原待执行节点。 |

语义选择本身不构成具体写入批准。未知提交结果继续保留原 operation、request key 和回执核实路径。
