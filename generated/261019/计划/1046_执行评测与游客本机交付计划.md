## 已确认边界

- 主模型保持 qwen3.8-flash；先找到可复现具体原因并修复，再最多发起 3 次全新只读探测，包括最多一次格式修复。超时、派发或用量未知立即停止；旧 unknown 不重发、不归零。若没有可复现原因，不以猜测的修复换取调用资格。
- EnterpriseOps-Gym 206 为主评，τ-Bench 80 为辅助。冒烟先用 CSM/ITSM 各 10 和 τ 各域 train 前 2；每域官方计分和受控 scoring-error 通过才全量。每路线逐任务独立重置；统计正式执行任务与总试次两个分母。
- ReAct、一次规划执行器、一次规划执行器 + Jev 三路线同业务输入/工具/权限/资源；后两者同计划同语义输入。结构化条件走规则，无模板则 N/A。历史 business-2 使用 schema 11 隔离库，不改冻结源码。
- Jev 评测继续累计 $1；Qwen 免费额度仍计请求/token。真实员工研究无参与者时保留待办。每类至少 100 个自动样本、95% 自动正确率要求不降低；当前不发布生产阈值。
- 无需注册的游客；每人独立模拟公司，7 天无活动过期，同浏览器恢复，不能跨设备找回；可清空空间和切换空间内员工/处理人/主管。
- 未有合格策略前，Jev 提供真实建议，由游客确认业务路径，业务写入另行确认；不伪造 confidence、不自动创建合格策略。
- 游客仅已注册模拟业务，不开放 Shell、真实公司 API 或实例管理。记忆按 workspace + 当前员工稳定槽绑定。
- 试用新增独立预算：全站每日 $5、5,000,000 Qwen token；单游客每日 30 任务、500,000 token，并行 1。全站并行 2、队列 20。金额、token、任务、原任务预算同时约束；unknown 保留预留，无法界定最大费用则不发请求。日界使用北京时间。
- SOP 专用 API/业务 Worker/业务 MCP/PostgreSQL Compose；不将旧 repair worker 在线当新 SOP 已部署。
- 公共仓库 CI/GHCR，独立私有部署仓库控制本机 Runner；语义版本标签触发受信发布，digest 部署，来源独立校验。兼容时应用回滚；不兼容数据库迁移失败停止，不自动恢复覆盖数据库。
- 本机短时中断可接受。域名购买、Cloudflare 实际公网入口、独立 Linux 验收后置；先完成本地体验和接入准备。

## 验收

执行器：参数映射、动态分支、状态重置、同状态配对、官方计分、禁止 gold 泄漏、未知写入不重放。游客：跨空间对象/trace/记忆/角色权限拒绝、会话过期与清理、额度并发、队列与重启恢复。交付：Ruff、Python 3.11/3.13、确定性、PostgreSQL 集成、核心浏览器 E2E、wheel MCP 与 Compose 冒烟、升级/故障/回滚演练。报告真实跳过与未完成项。

文档分别归档智能体与 Jev、评测、游客使用、代码仓库、CI、CD、本机部署，各自索引并标记已实现/设计/待验收，含流程、泳道、时序、恢复图。
